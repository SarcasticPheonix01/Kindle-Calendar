# Kindle-Calendar
A simple calendar to be run on a jailbroken kindle. Text based and similar in functionality to a dated notepad.

## Set Up
In order to use this project your kindle has to be jailbroken, with KUAL, mrpackages, and Python installed. Please follow the instructions over at https://kindlemodding.org/ to get the initial jailbreak. Install k-term using the instructions at https://www.fabiszewski.net/kindle-terminal/. After, you will need to get Python and install it as *python3* in the root directory. There is no straight forward way to do this on kindles, as they can be finicky with hard vs soft point systems. 

First, try using NiJuLe's version at https://www.mobileread.com/forums/showthread.php?t=225030.

This did not work for me however. After some struggle I downloaded the file *python3.11-khf-1.1-source.zip* from https://www.mobileread.com/forums/showthread.php?t=367713 and manually extracted the file *python3*. I have had no problems with this, and it runs fine.

The Kindle I have been using is a PW4, which may have caused compatibility issues with the method used to install python the intended way. The calendar has been tested on a KT3 and should work on any kindle, as long as it can run Python 3.11 or above. If you find that it works on other devices please let me know, and if it doesn't work/breaks something also let me know.

### Confirmed Compatible Devices
- KT3 Kindle Basic 2 (2016)
- PW4 Kindle Paperwhite 4 (2019)
